- **Spell item sheet → Mechanics tab → a row's Edit button (the effect-row editor):** a row of the tracked kinds (illusion, detect, light, dispel, object, wall) and the new delayed-affliction kind gets a Lasts field, the spell's duration or instant, keeping any value already stored. A delayed-affliction row picks the effects it holds back from the Effect keys list. A summon row gets a When control ends select (They stay, They go, They turn hostile), which an imported summoning spell arrives with and a Judge can change.
