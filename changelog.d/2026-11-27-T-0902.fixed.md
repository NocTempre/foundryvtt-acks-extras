- **On a scene that auto-sizes tokens, a token a formation re-creates, or a pasted token, keeps a size set in its Token Config.** Joining or leaving a formation and the start and end of a fight re-created the token and fitted it to its footprint again, undoing a hand's width and height. A size that differs from the actor's prototype and is not the one the module last wrote now stays; the size chips' reset and Map setup's Rescale tokens on scene still re-fit it. The setting is Scene configuration → Basics tab → Battlemap → Auto-size tokens.
