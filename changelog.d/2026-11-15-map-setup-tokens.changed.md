- **Scene controls → Battlemap → Map setup → Token sizes:** the section now says what its chips do (they set the selected tokens' footprint, in feet), labels each chip in feet with a tooltip of the cell and step it comes from, and holds the "Rescale tokens on scene" button, moved up from the foot of the panel. A line says whether tokens placed on the scene are auto-sized and where to change it (Scene configuration → Basics tab → Battlemap → Auto-size tokens). Where a cell is a mile or more, the section is one line saying tokens there are not sized to footprints. A chip, the reset or the custom size pressed with no token selected says so instead of reporting "0 token(s)", the custom size works on a value typed and clicked at once, and a rescale says how many tokens kept their size because their footprint is not imported. A rescale no longer counts tokens that already hold the size.
