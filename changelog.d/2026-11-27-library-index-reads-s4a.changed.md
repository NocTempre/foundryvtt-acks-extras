- **A companion pick, a summoning cast, a lair's Roll and the token art pass load only the creatures they name.** The companion picker, which opens when a companion ability is dropped on a character or from the plus control of the Companions section on a character sheet's Equipment tab, loads the library's animals and no other creature. A summoning spell cast from the Cast dialog finds the creature its row names, and the summoning check finds the spell's library entry, by one request each, where each used to wait for the whole library to load. Roll in the Lair section of a place's sheet finds its monster the same way. Overhead tokens from … and Restore book tokens, on the Tools tab of Manage Imports (Settings tab → Game Settings → ACKS II — Extras → Manage imports), load the imported monsters alone.
