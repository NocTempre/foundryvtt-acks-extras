- **A once-only item can be set to be used up by its use, and a use then spends its count.** A once-only item had no control for this, so its Use never took anything off its Quantity and a stack of one stayed Ready for ever. Item sheet → Details tab → Effect rows → a row's Edit (the pen) → the Reach group: where "How it is used" reads Used up for a once-only item, an "Each use spends one" box appears. Ticked, each use takes one off the item's Quantity once its effect has been written (three reads two), and the last one leaves the item at none, kept in the inventory, reading Used up with its Use press off and no Token HUD control; Use on it again is refused. Unticked, a use leaves the Quantity as it is. A use that is refused or fails before its effect spends nothing, and an item with no Quantity is untouched. Moving "How it is used" away from a once-only item, or to one, clears the box. The count stays editable by hand: Actors sidebar tab → an actor → Inventory (or Equipment) tab → the item's row → its sheet → Quantity.
