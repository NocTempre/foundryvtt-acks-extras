- **A rebuilt Adventure with its pictures already made reads no PDF for the walls either.** The text saved beside a staged book's PDF now also holds the walls traced for each of the book's maps that has walls, so rebuilding a book's Adventure (**Settings tab → Game Settings → ACKS II — Extras → Manage imports → Adventures** tab → **Write Adventure**) builds a walled map's walls from the saved trace instead of rendering the page again; a map whose recipe changed since the book was read, or whose trace is missing, is still traced from the PDF. Reading a staged book the first time now takes longer for a book with walled maps, since the walls are traced then. A book's saved text from before this change is read again, once, by the next GM seat to need it.
