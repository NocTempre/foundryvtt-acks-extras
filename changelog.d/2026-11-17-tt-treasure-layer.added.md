- **Imported rules tables → Treasure and Magic item tables:** with the Treasure Tome connected as well as the Judges Journal, the Tome's own version of the treasure types, gem and jewelry values, special-treasure lists, Creature Type list and arms-and-armour grids replaces the Journal's, whole, in the Ruledata Browser (`Settings tab → Game Settings → ACKS II — Extras → Imported Rules Tables → Open Ruledata Browser`) and in their RollTables; the Tome's Gritty treasure types appear beside Classic and Heroic. Without the Tome nothing changes, and a table already read from it is kept when you reimport with only the Journal connected.
