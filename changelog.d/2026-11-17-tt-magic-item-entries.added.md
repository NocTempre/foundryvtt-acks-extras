- **Settings tab → Game Settings → ACKS II — Extras → Manage imports, the Rebuild tab, Shelf, book or tables → Magic Items** (and the Import Everything chain): with the Treasure Tome open, the importer reads the Tome's magic-item entries from your copy and makes each a core item, named and described from the page, filed under the book's folder by kind (potions, rings, scrolls, implements, miscellaneous items, swords, miscellaneous weapons, armour). The markets flag of each item holds only the base cost and apparent value the page's header line gave; a figure not read is left blank. A Judge's edit of either survives a repair. This first batch holds the opening potions entries; the rest of the chapter follows. Where the Tome and the Judges Journal both print an item, the Tome's entry is the one kept. After the tables are imported, a magic-item roll's result carries `item.uuid` for a row linked to its imported item, which the treasure tools read; the roller's card does not show the link yet.
