- **The class builder's weapon-narrowing cost:** the fighting value from which narrowing a class's weapons adds experience, and the cost per power gained, are both read from your own Judges Journal (JJ p. 292) at import, and a weapon trade-off adds its cost to "XP for 2nd level" only from that fighting value. With either figure not imported, or a trade-off's benefit not read, the trade-off adds no cost and counts no power. Items sidebar → open a class → Builder tab → Advanced mode → **Trade-offs** (a class's **Accounting** line); the figures are under Settings tab → Game Settings → ACKS II — Extras → Imported Rules Tables → the `acks.classBuilder` document.
