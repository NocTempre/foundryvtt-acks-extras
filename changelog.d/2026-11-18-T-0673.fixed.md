- **Books open on a host that serves module files from a separate file server (Settings tab → Game Settings → ACKS II — Extras → Manage imports → Books tab; the same for a shelved book, and for Actors tab → Import sheet):** on such a host, The Forge among them, every PDF failed to open with "Setting up fake worker failed". The module asked for its PDF reader's worker script at the game's own address, the host redirected that request to its file server, and a browser does not start a worker from a redirected script. The module now asks for the script at the address the host served the module from. A self-hosted or desktop game opens books as it did.
