- **Settings tab → Game Settings → ACKS II — Extras → Manage imports → Import tab:** an adventure's encounter zone on a hex map or a square-grid dungeon plan now imports as one Region with core's grid shape over its cells, where a hex zone used to be a separate polygon for every hex and a dungeon level one outline. A Judge can unlock it and add or remove cells with the grid tool under **Scene controls → Regions**, and wandering-monster throws read the cells as edited.
