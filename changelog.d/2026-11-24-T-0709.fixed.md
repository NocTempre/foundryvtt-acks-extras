- **The Beastman family template shows the family's own picture.** It showed the first breed's portrait, and the full-page picture of the Monstrous Manual's Beastman section was imported nowhere. The template now takes that picture, and each breed keeps its portrait: Compendium Packs sidebar tab → ACKS II — Extras → From your books → ACKS Cookbook — Actor → Beastman. A template imported before this release takes it on a repair with the Monstrous Manual open: Settings tab → Game Settings → ACKS II — Extras → Manage imports → (Re)import individual entries, with the Beastman family row ticked. A picture you set on the template yourself is kept.
