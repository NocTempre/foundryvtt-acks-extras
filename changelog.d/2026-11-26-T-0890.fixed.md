- **The importer's failure lines open with a sentence in the interface language, and every importer notification carries one module prefix.** A book that cannot be added to the server and a scan of the server's shelf folder that stops show the reason on the book's row or under the scan, in Settings tab → Game Settings → ACKS II — Extras → Manage imports → Books tab; a table import that stops says so in a notification. Each line used to show only the raw English error, and now leads with the sentence and ends with that error as detail. A book-open warning about a different edition or printing is worded the same way. The notices that a book was opened, that its text was saved, refused or could not be read, and that tables were imported or skipped carried their own "ACKS Extras |" title, and now open with the module id like every other importer notice.
