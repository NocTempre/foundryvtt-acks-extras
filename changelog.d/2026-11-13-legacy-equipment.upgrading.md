- **Equipment written by earlier versions is no longer read in its old shape.** A weapon's old thrown, handy or hands flags no longer change its grips or class, a named item's old stored maximum no longer sets its rungs, and the repair tool (Settings tab → Game Settings → ACKS II — Extras → Repair this world) no longer lists garments whose base type and clothing type disagree. Re-import the weapons and armour: Settings tab → Game Settings → ACKS II — Extras → Manage imports → Import everything.
