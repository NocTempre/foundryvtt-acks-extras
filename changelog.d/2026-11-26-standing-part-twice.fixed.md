- **Two writes of one standing part on a body can no longer collide and stop a raise on "already exists".** A body inside a standing reach holds one record for the part, under a fixed id. Where two writes of that record overlapped (a raise holding the part on its own bearer and the reach's entry moment holding it too), each read the body before either had written, and the second asked the server to create the same record again, which it refused, so the raise threw. A body's writes now run one at a time and the second finds the first's record there: Actors sidebar tab → a monster → Inventory tab → an item with a standing reach → Raise.
