- **The first Deal, the first Draw and the first attack after loading no longer wait for the whole imported library.** In Scene controls → Token controls → New treasure pot, the Treasure window's Deal button, a weapon row's Draw control (character sheet → Equipment tab) and an attack rolled from the character sheet each held for as long as it took to load every imported shelf, many seconds in a large library, and a hoard with no magic in it waited just the same. The Draw and the attack now read only the weapon and masterwork documents they need, a Deal of a hoard with no magic reads no library at all, and a Deal that rolls an arm reads only the weapons, armour and masterwork documents. A magic item the Deal links to is found from the shelf's index, so a Deal that rolls magic loads no whole shelf for it. Setting a masterwork tier or silver plating on an item (an item's sheet → Details tab → Construction) reads the masterwork and silver documents alone, and an attack made after the page sat idle keeps its masterwork bonus, which used to read as not imported once Foundry had dropped the shelf. The library's own load at startup now begins after the weapon rows and the class tables have been read, rather than beside them.
- **A weapon or a class edited after the page had sat idle keeps every row and every class table.** The weapon rows and the class tables are read again from the shelves' indexes, so an edit republishes all of them and no longer only the one document still held. A long import of weapons no longer holds an attack back until the import ends, and a shelf that cannot be read leaves the rows and tables as they were published, with a warning in the console, instead of publishing a short set.
