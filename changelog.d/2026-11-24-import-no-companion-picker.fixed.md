- **Importing a character no longer opens a companion picker for each ability that grants one.** An import that fell back to the world sidebar, and a repair of a character standing there, opened one picker per such ability on a seat nobody was watching, and answering one made a world creature and wrote it into the library character. An import now leaves the companion slot empty, to fill from the character sheet's Equipment tab → Companions section. Adding an ability by hand, at character creation or at level-up still offers the picker.
