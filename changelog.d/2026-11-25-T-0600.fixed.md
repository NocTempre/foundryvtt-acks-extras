- **A stroke of the Country brush on a layer the map is not showing now switches the map to that layer's mode.** With the brush armed on Territory, picking Terrain or turning on Handout view in the Map modes window left every stroke writing to a layer nothing drew. The first stroke after such a pick now shows the layer's mode (Territory, Domains), turns the handout off and opens the Map modes window; a pick with no stroke after it stays as picked, and a stroke on the Terrain layer changes nothing. The brush is Scene controls → Battlemap → Country brush, the window Scene controls → Battlemap → Map modes.
