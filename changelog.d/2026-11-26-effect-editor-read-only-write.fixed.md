- **An item's or ability's effect-row editor no longer sends a change the seat may not write.** A seat that only observes an item (a Player looking at a character's gear it does not own) could still reach the effect-row editor's fields in a window opened another way, and a change there asked the server to write the item, which refused it with a "lacks permission" error and a toast. The editor now writes only for a seat that owns the document, and the group already shown read-only stays read-only: Actors sidebar tab → a character's sheet → Equipment tab → an item → its effect rows → Edit.
