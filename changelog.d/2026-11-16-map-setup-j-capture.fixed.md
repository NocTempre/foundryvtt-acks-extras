- **Scenes sidebar tab → right-click a scene → Configure → Basics tab → Battlemap → *Calibrate…*:** the button opens the map setup for the scene whose configuration you are in; it used to open whichever scene you were viewing. While a sampling mode is armed in the map setup window, Ctrl+Z and Escape typed into a field (the window's own inputs, chat, a journal page) now stay with that field: Ctrl+Z undoes the text and no longer deletes a sample, and Escape no longer disarms the mode. On the canvas they act as before.
