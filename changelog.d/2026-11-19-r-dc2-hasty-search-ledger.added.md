- **Macros and companion modules, `acksExtras.formation.traps`:** `hastySearchLocked(placement, actorId, level)` says whether a character has already failed the automatic hasty search of a trap at their current level, and `recordHastySearchFailure(placement, actorId, level)` records one failure and returns the ledger it wrote. Both take any trap placement (a Trap Zone, a trapped wall or a trap thing) and read and write the same record the party's automatic search keeps, so a search made elsewhere honours a failure the party's search made, and the reverse. The formation API version rises to 36.
