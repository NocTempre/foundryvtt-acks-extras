- **A state such as Defend, toggled on a token while a fight that token is not in was running somewhere in the world, no longer counts as given by that fight's acting combatant.** Foundry marks every new effect with the world's current fight, so a Defend taken by a creature outside it read as a gift from whoever was acting there, and the shield figures on its rolls were held back as unknown. A state now reads as given only where the creature is itself in the fight it was made in; otherwise it is the creature's own. Take or drop it from Token HUD → Status Effects.
