- **Import Everything reads the library once per step, not once per item it updates.** Core asks the server for an empty list of documents twice per compendium update, and the server answers by scanning the whole pack; that empty request is answered without the server. The skill-ladder cache reads the world's Item packs once after item changes stop for a second, ignores a character's own items, and keeps the newest read.
