- **Items sidebar or an actor sheet → an item → its sheet's Details tab: a carried item lists its effect rows at the foot of the tab, with Add row, and Edit and Delete on each row.** Add row opens the same editor an ability's effect rows use, so a Judge can give an item its first row, and a row the importer wrote can be changed there. The buttons are drawn for whoever may edit the item; anyone else reads the list.
