- **A class whose training paragraph sits beside its level table imports its training.** The Rulebook's class on p. 98 prints its Combat Proficiencies paragraph with the level table's cells through it, so the import read none of it and the class carried no training effect. Its weapons, armour and fighting styles are now read from the paragraph's own box on the page: Settings tab → Game Settings → ACKS II — Extras → Manage imports → Import tab → **Import everything**, then the class sheet's Overview tab shows the training. A class with no such box still reads its body text.
