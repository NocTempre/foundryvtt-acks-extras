- **Compendium Packs sidebar tab → the *ACKS Cookbook — Judge — …* compendiums:** on a player's seat the module no longer loads these compendiums when the world opens, and its own lookups there (a class's spell choices, gear found by name, the shop's sources, the catalogue of goods, a summoned or recruited creature) read only the compendiums that seat is shown. A Judge's seat reads them as before. The docs site's Compendia reference no longer says a player cannot read them: Foundry does not list them for a player or open their documents, and it still answers a macro or script run on a player's seat that asks for one, so they are out of sight and not secret.
