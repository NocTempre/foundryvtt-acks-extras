- **Starting kits share one library of items.** A class's starting template links the imported item itself when it names it plainly ("Torches" links the Torch, with the count on the kit's row), and a kit item with a printed descriptor or price is made once and linked by every class that prints it, in a Class Templates / Shared folder beside the class's other kit documents (Compendium Packs sidebar tab → the ACKS Cookbook Item shelf, or the Items sidebar tab for a class of your own), instead of once per class.
