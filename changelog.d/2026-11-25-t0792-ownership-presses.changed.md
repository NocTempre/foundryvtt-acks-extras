- **Undo, Revert, Dismiss, Restore and a spell-less Summon… follow what Foundry lets a user touch, where only a Judge's seat had them.** On a cast's card in the chat log, Undo on an entry is offered to the owner of the target and to the user who cast it and owns the caster, and Revert (for a tradition's performed step) to a user who owns the caster and can edit the card; where the user cannot write the target, the connected Judge's client carries Undo out, taking back only what that cast wrote, and a press it declines is told to the user on the spot. On the card a summoning's end posts to the chat log, Dismiss is offered to an owner of the caster, except for creatures that turned hostile when their control ended (RR ch. 5), which only a Judge dismisses; on a concentration's end card, Restore is offered to an owner of the caster, and a Restore that cannot write another owner's character restores what the user owns and says how many it left. The cast menu (Character sheet → the cast cell, the wand) offers a spell-less Summon… to a user whose role Foundry grants Create Tokens (Settings tab → Game Settings → Core → User Permissions → the Create Tokens row), and a creature the user cannot open is still refused. The sheet's Dismiss (Character sheet → Magic tab → a summoning spell's row) now refuses only a creature that turned hostile.
