- **A weapon's fighting-style row names the style and what grants it.** The row printed the style's internal id (`weaponShield`) and always tagged it "Class". It now prints the style's name and tags the class that trains it, "Ability" or "Proficiency" when one of those trains it instead, or "No class grants it" when the style is untrained: a weapon's item sheet → Effects tab → Inherited.
