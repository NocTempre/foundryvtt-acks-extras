- **Importing a character sheet PDF that lists one item in two places now places two units of it.** A dagger listed in both hands, or in a hand and in the backpack, used to answer both lines with one row, so the second line moved the first one's dagger (out of the main hand, or into the pack) and left the other where it was. Each line now takes its own unit of the stack, a re-import moves nothing, and a line with no unit left to place (the character holds fewer than the sheet lists) moves nothing and is named in the import report: Actors sidebar tab → Import sheet (a new character), or the character's window menu (⋮) → Official sheet (PDF) → Import.
