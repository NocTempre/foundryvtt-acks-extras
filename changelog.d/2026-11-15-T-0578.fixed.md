- **Scene controls → Battlemap → Map setup panel, on a hex map:** boxes drawn around single hexes on different rows now agree. Before, a third box on the next row read about 20% loose with a warning to add samples, and more boxes made it worse. The panel now fits one hex grid to every box you draw. It shows how far the boxes sit off in image pixels. A loose fit names the box furthest off and asks for boxes drawn between the others. A box too far from the rest to place is counted and left out, as is a box that is not around a single hex. When the boxes read as the other hex family, the panel says so and keeps your choice. "Pick corners" is refused on a hex map with a notice naming "Draw box", and the "spans" box is no longer offered there. A scale bar's length now converts centre to centre between hexes.
- **Map setup panel:** a disabled Apply button now says why, one line per missing step, each naming the control that closes it. The "One drawn hex is" field is blank and asks for a value when the unit you chose is not the scene's, instead of offering the scene's old distance under the new unit. A scene that already matches says so. The done notice names the grid and the unit. The confirmation no longer says placed tokens, tiles and walls move with the map; they stay where they are. An apply at a mile or more a cell turns the scene's token auto-sizing off (Scene configuration → Basics → Battlemap → Auto-size tokens), even where it was on. "Allow skew" and "Independent X / Y", shown only for a square grid, no longer steer the fit after you switch to another grid.
