- **A helmet worn with a suit no longer counts the suit twice.** On the ACKS II system 14.2.0 a character's Armor Class already adds every armour worn, so the module's own correction for a helmet doubled the suit's figure; it is gone, and a second shield is cut or kept by the same two rules as the first. The Armor Class tooltip now names every armour the system adds, each with its figure, and their total: character sheet → Stats tab → the Armor Class row.
