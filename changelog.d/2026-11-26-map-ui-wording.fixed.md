- **A wall's sheet (Walls layer → double-click a wall) no longer throws away what you type into a row that has no layer.** Under "Not a road" the Road row's street kind and name are greyed out, and so are the Water row's boat tick and name under "Not water". Each comes back the moment you pick a surface or a kind.
- **The Map Modes window (scene controls → Battlemap → Map modes) shows the opacity figure beside its slider.** In Terrain, which draws no borders, the slider is greyed out and a line says to pick a mode first.
- **The map tools now use the party sheet's names for the three party systems: Delve, Journey and In the city** (they said Dungeon, Wilderness and Settlement). This covers the scene card's icon and picker in the Scenes sidebar's navigation bar, and **Party system here** in the Map setup window (scene controls → Battlemap → Map setup). Choosing no system now reads "Not declared", the icon's own word for it, where it said "Leave to the party".
- **In the Map setup window, the size hint on a hex map now speaks of a Foundry hex**, not a square. The hint for picking corners now says that rotation and skew need **Allow skew** ticked under **Fit**.
