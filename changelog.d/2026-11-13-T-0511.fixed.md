- **Culture names in the name generator and the Location sheet's Demographics are read from your book.** A
  culture's label comes from its heading in the Revised Rulebook when Rules tables is run for the People
  document (`Settings tab → Game Settings → ACKS II — Extras → Manage imports`), and a culture whose book is not
  imported shows as `Culture N`. The Add button on a Location sheet's Demographics block (GM Settings tab) starts
  the row on the first imported culture, or on none when nothing is imported. The form a generated name takes
  after the given name (a father's name with its affix, where a culture's section prints one) is read from that
  section too, so a candidate's name carries it only once the People document is imported; a Judge can edit it
  in `Settings tab → Game Settings → ACKS II — Extras → Imported Rules Tables → Open Ruledata Browser`, under
  the People document's `cultureAppearance` table.
