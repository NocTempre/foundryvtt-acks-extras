- **Divine and arcane power are one icon each on the casting strip, shown only for a character that has the power.** Under Actors sidebar tab → a character → its sheet, the casting strip (the Magic tab on the module's sheet) draws an icon for each power the character's class casts, or whose ledger holds entries, or, for arcane, that a Judge marked as the class power; a character with none draws nothing. While the balance is above 0 it is drawn as a number over the icon. Clicking the icon opens that power's entries, the owner's controls and the Sacrifice button, which moves in from the strip line.
