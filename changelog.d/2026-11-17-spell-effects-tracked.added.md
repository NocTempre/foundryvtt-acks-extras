- **Casting thirteen first-level spells that only create an effect (the Chat tab's cast card, and a spell item's Mechanics tab):** an illusion, detection, light, dispelling, object or wall spell now carries effect rows, so casting it from a character sheet posts a card with a footnote line for the row and, for a row that lasts the spell's duration, writes the caster's record that ends with the duration. A row that is spent in the cast writes no record, and a spell with reversed rows casts its own reversed rows when the cast dialog's reverse mode is chosen. Nothing is rolled or thrown for these rows, and a dispelling row shows no Throw button. Importing spells reads the saving throw category from your own copy of the book for the three spells that print one, and the save modifier for the one that prints a bonus; the sizes and radii of these spells are left blank.
