- **Judges: check the places you made from unfound points of interest.** One made before this version is still owned by every player, hidden token or not. To close it: Actors tab → right-click the place → Configure Ownership → All Players: None. No tool changes them for you.
- **Judges: a place the importer writes straight to the Actors tab is no longer opened to every player.** The importer does that only when it cannot open a compendium, and says so with an error notice. Such a place (a keyed area, a district, a point of interest, a market) used to arrive owned by all players; it now arrives with Foundry's own default, None, as one dragged out of a compendium always has. To give one to the table: Actors tab → right-click the place → Configure Ownership. A place you make by hand in the Actors tab is still opened to the table.
