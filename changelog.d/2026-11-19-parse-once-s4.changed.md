Importer: each staged book's row in the Books tab now shows where its saved text stands. Open the **Your Books** macro (**Compendium Packs tab → ACKS II — Extras → Macros → ACKS Extras Macros → ACKS Extras → Your Books**), and in the Books tab's **On the server** band a chip says Prepared, Not read, Stale, Reading or Refused, with a line saying what that means and a tooltip naming the saved file, the PDF and the reader behind it. A GM gets **Read now** (nothing saved) or **Read again** (otherwise) on the row, which reads the book's text from the file on the server and saves it for every seat, with the page it has reached while it runs and a notification when it ends; **Remove** waits until the read ends. A Refused book, whose file a check this session found gone or not the staged one, offers **Remove** only. With more than four books staged, the folded list reads "Staged on the server (N)" followed by how many are stale or refused. A Player sees each book's chip and line and none of the controls. The tab's notes no longer say a staged book is read from the server on every launch or that the file is never stored.
