- **A state that brings a condition carries that condition's figure on its own effect, and the same condition set twice counts once.** Charging, Countercharging and Retreating bring Disordered, and Starving and Underfed bring Hungry. The one effect that Token HUD → Status Effects makes for each of them now holds both the state and the condition it brings, with both figures, and a character's Armor Class and saving throws take the brought condition's figure from it. A condition set by hand beside such a state, or brought by two states at once, applies its figure once, on a character and on a monster, and the attack card's Armor Class line, a monster's Armor Class and its saving throws read the same single figure. The card's line also names a step an Armor Class waiver spares on a character, since the system has already counted it. An effect of one of these states made before this update does not light its tile in Token HUD → Status Effects: a click makes a new one beside it, and the old one ends at the turn's end as before or is lifted by hand from the character sheet's effects list.
