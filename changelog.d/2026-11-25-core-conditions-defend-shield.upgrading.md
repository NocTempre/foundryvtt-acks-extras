A palette arrangement you saved with it (`Settings tab → Game Settings → ACKS II — Extras → Token status palette`), a defence's or an effect row's `conditions` set, a `status` gate's text that names it, and a Rules tables import that read its figures stop being recognised, and nothing repairs them. Defending's thrown, missile and Blast figures read as not imported until you re-run the Rules tables import (`Compendium Packs → ACKS II — Extras → Macros → ACKS Extras Macros → Reimport One Shelf (GM)`, choose **Rules tables**).
