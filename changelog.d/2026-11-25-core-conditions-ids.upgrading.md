- **Judges: three condition ids changed, and what a world stored under the old ids is not carried over.** `concentratingStationary` is now `concentrating-and-stationary`, `covered` is `cover-waist-high` and `coveredGreater` is `cover-chest-high`, and `vomiting` is new. An effect or token carrying an old id, a palette arrangement you saved with one (`Settings tab → Game Settings → ACKS II — Extras → Token status palette`), a defence's or an effect row's `conditions` set or a `status` gate's text that names one, and a Rules tables import that read cover's figures under the old ids stop being recognised, and nothing repairs them: take the mark off and set it again, choose the condition again in the row, and re-run the Rules tables import (`Compendium Packs → ACKS II — Extras → Macros → ACKS Extras Macros → Reimport One Shelf (GM)`, choose **Rules tables**) for the cover figures. A token that carried Foundry's silence status now carries Mute, as the ACKS II system maps it, and the module turns a creature's shadowy senses off for Deafened and not for Mute: set Deafened (Token HUD → Status Effects) where the silence is meant to take them away.
