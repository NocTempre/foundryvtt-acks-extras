- **A condition shows the ACKS II system's own name and icon, and the states of a round sit apart from the conditions.** On the token HUD (Token HUD → Status Effects) and in the Token Status Palette window (`Settings tab → Game Settings → ACKS II — Extras → Token status palette → Arrange the palette`), every condition the system ships, and its tracker's Readied and Delayed, reads as the system names it and draws the system's icon, in the language the system is set to. Under **States** now sit the module's own marks (Dead, Invisible, Running, Casting, Countercharging, Defending, Defending with a Shield, Retreating, Withdrawing, Diseased, Frostbitten and the two cover grades, shown as "Cover, waist-high" and "Cover, chest-high"); **Conditions** holds the system's conditions and the three the system does not ship (Immune, Resistant, Subjacent); Readied and Delayed move to **Combat tracker** and stay on the palette. Choking and Vomiting are now two conditions, as the system has them. The ability sheet's condition lists, the cast card and the spell description name a condition as the system does.
