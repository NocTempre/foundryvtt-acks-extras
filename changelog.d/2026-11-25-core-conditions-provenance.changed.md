- **The Armor Class and saving throw modifier tooltips name each effect that moves them.** Hover an Armor Class figure or the saving throw modifier beside its label on the character sheet's Stats tab: the tooltip states the stored value, then one line for each active effect, by the effect's name and its step (a charge's Armor Class step names the condition it belongs to, Disordered), then a line for any change no effect accounts for, in the shape of the attack card's own breakdown. When a monster rolls a saving throw that a condition's effect changes, the notice that tells the table names each step by its effect.
