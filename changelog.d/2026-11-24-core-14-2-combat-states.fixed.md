- **The combat tracker's Done control works again with the ACKS II system 14.2.0.** Pressing Done on a combatant failed with this module on, because the system's Done and Overnumbered states were no longer registered; they are now, and stay off the token HUD: Sidebar → Combat tracker → the Done control on a combatant's row. The system's own "Include Foundry core status effects" (Settings tab → Game Settings, in the system's section) now decides whether Foundry's own statuses start on the token palette, and this module no longer renames Foundry's old status ids itself, since the system's upgrade does that; the palette is Settings tab → Game Settings → ACKS II — Extras → Token status palette.
