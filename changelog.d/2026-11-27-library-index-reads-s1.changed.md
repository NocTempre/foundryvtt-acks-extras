- **Editing items in the Items sidebar tab no longer reloads the item library on every seat.** After an item there is created, changed or deleted, each seat refreshed the skill ladders (what a throw borrowed from a skill reads) by loading every imported Item compendium whole again; it now reads each compendium's index and loads only the imported skill definitions it does not already hold. A cast or other library action started just after a page loads no longer loads the item compendiums a second time beside the library's own load, and the trade goods a market reads from a compendium's Merchandise Items load in one request per compendium instead of one per good.
