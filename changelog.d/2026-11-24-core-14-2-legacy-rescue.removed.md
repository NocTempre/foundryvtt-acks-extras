- **The repair check for records the system stamped without renaming is gone.** The ACKS II system 14.2.0 repairs those records itself the first time a GM opens the world, so the module no longer reads old attack throw, Armor Class, saving throw, damage, bonus, tag and weight fields back at load, and the check that wrote them is removed from Settings tab → Game Settings → ACKS II — Extras → Repair this world → Open the repair tool. A weapon whose stored damage names no alternate die now shows the system's default alternate die until a Judge clears it, or until the check for weapons whose alternate damage differs from their imported row blanks it.
