- **Remove ALL imports no longer deletes the kit parts of a class you made.** It used to delete every part in the Class Templates folder, the bundles and 3d6 table of your own classes and the shared gear skins among them. It now deletes only the parts of imported classes; a class you made keeps its bundles, its table and the shared parts. Where to look: Settings tab → Game Settings → ACKS II — Extras → Manage imports → **Remove ALL imports**; the parts stay in the Items sidebar tab → Class Templates. Parts an earlier removal already deleted do not come back.
