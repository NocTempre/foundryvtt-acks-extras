The quiver and the bolt case from the weapons grid are named from your own book's label, bundle size included, instead of from a built-in name, so no bundle size is built in. Import weapons from Settings tab → Game Settings → ACKS II — Extras → Manage imports → Import everything with the Rulebook connected; an item's Annotate then reads the bundle size from that name. A quiver or case whose name states no size declares none and is treated as a plain container.
