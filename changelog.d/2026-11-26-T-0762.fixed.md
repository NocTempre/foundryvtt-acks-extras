- **A repair or a rules-tables import now keeps your own edits to a class's build and race.** Applying the class-builder tables wrote a class's build fields (hit dice, fighting, thievery, magic, racial value, notes) and its race over whatever the class held, so a Judge's change to them was lost on every Repair everything. The import now records what it wrote; a field you changed since is left as you set it and listed with the repair's other kept edits. A class imported before this release has no record yet, so its first apply still writes. Where to look: Settings tab → Game Settings → ACKS II — Extras → Manage imports → Import tab, **Repair everything**.
