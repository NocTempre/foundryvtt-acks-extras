- **Combat Tracker sidebar tab → the group control: a second group no longer takes the first group's initiative modifier, and grouping several in a row, from a macro or when a group token joins a combat, keeps them all.** The system gave every group already in the combat the lowest initiative value among the tokens of the newest group, so each group rolled with the wrong modifier, and a group made before the last one had landed was dropped from the list. Each group now keeps the lowest value among its own members, and the control's call now returns its write, so a caller that waits on it makes the next group on a list that has the last.
