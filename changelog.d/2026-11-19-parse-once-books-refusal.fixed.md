Importer: the Books tab (**Settings tab → Game Settings → ACKS Extras → the importer manager's Books tab**) now redraws a staged book's row and the folded list's counts the moment a check refuses the book, so a **Read again** that finds the file gone shows Refused with **Remove** only and "1 refused" at once, instead of after the tab is reopened. A Player's folded list counts only the books it is shown a state for, so a stale book the Judge has not shared no longer adds to "stale". A Refused mark belongs to the file it was found against: removing the refused journal while the book has a second one no longer leaves the second reading Refused with a tooltip about a file nobody checked.
A book whose file was found gone stays refused: a Read again that finds a 404 now lapses the handle's earlier vouching, so the next check asks the file again instead of clearing the refusal and reverting the row to Prepared, and a book whose file is gone cannot license a delete.
