- **Deal a monster's treasure into a pot.** A staged treasure pot's left rail
  (Scene controls → Token controls → New treasure pot) now lists the selected
  monsters, one row per kind with its treasure type, beside a Treasure type
  field, a table style, Special treasure and a "Met in their lair" toggle; Deal
  rolls one hoard per ticked row into the pot face down. With the toggle off,
  Deal first asks the Judge to confirm. A monster sheet's Ecology tab gains a
  Judge-only Deal beside Treasure type that opens a pot staged with that
  monster.
