- **Re-importing a character sheet PDF no longer raises a gear item's count when the sheet lists it on two lines.** A sheet with two Torch lines of 3 and 2 gave 5 on the first import, then 7, then 9, each with a false "sheet 3 / in force 5" check; a dagger listed twice, with one drawn, grew the same way, and an item carrying Active Effects of its own was topped up again on every re-import. Every line of an item the character carries as a stack is now answered by that stack and checked against the lines' sum, and a count you changed by hand is still reported, never overwritten: Actors sidebar tab → Import sheet (a new character), or the character's window menu (⋮) → Official sheet (PDF) → Import.
