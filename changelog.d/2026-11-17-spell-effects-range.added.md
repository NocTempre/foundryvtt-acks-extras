- **Character sheet → casting a spell that has effect rows (the cast dialog):** a spell whose range names a distance, once imported, is measured to each targeted token (centre to centre on the scene grid), and a target beyond it shows an out-of-range line under the targets. A Player cannot cast until it is fixed and a Judge is warned; hover the line for each target's distance and the range's parts. A target count read from the import caps the number of targeted tokens in the same way. Where the range cannot be measured (no caster token on the scene, a target on another scene, an area's size not imported) the dialog says so and nothing is judged. A spell whose choice has several rows per option now lists each option by every row it carries, and a spell that makes its targets roll saves rolls them only when a damage, heal or condition row of the cast is theirs to resist.
