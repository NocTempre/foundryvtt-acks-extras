- **The loadout notice for a second suit of armour or a second shield names every one worn.** It named all but the last equipped, as if only the last counted, but system 14.2.0 adds the Armor Class of every equipped armour and shield while they stand. The notice comes up when one is equipped from a character sheet's equipment list. With the equip limits set to resolve, the last one equipped is still the one kept.
