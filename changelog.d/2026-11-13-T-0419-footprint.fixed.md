- **Token sizing reads the square from the monster book import.** What one battle-grid square is worth
  comes from the Monster Size table of the Monstrous Manual import (`Settings` tab → `Game Settings` →
  `ACKS II — Extras` → `Manage imports` → Rules tables), beside the frontage it multiplies, and a Judge can
  edit it in the Ruledata Browser. A token whose square or size frontage is not imported keeps the size it
  has, and the assistant's Rescale tokens notice says so. The assistant's distance chips and its unentered
  map-cell default follow the scene's own grid distance.
