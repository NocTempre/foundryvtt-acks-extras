- **Answering No to a Repair confirm now leaves your world as it was.** The check before the question used to read the whole book and save its text, so a No still left a saved file and a changed shelf journal, and the question waited for the full read. The check now opens the book's file and nothing more; the text is saved on the first read after a Yes. Where to look: Settings tab → Game Settings → ACKS II — Extras → Manage imports → Adventures tab, **Repair** beside a book, or the Import tab, **Repair everything**.
