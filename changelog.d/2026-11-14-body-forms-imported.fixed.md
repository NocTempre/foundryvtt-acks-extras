A monster sheet's Body Form list (Classification tab) offers the body forms the Rules tables import reads from your Monstrous Manual (MM p. 389), each with its sample monsters; run it from Settings tab → Game Settings → ACKS II — Extras → Manage imports → Rules tables, and edit the list under Settings tab → Game Settings → ACKS II — Extras → Imported Rules Tables. With no table imported the list is blank and its tooltip names the page, and a form a monster already holds is kept. The glyph on a monster's band follows its form, and `BODY_FORMS` is not in `acksExtras.monsters.config`; the library API version is 43.
