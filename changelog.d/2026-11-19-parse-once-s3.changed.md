- **A rebuilt Adventure with its pictures already made reads no PDF for the maps' placement check, and a re-pointed book is read again.** The text saved beside a staged book's PDF now also holds where the pictures sit on the pages that maps are cut from, so rebuilding a book's Adventure (**Settings tab → Game Settings → ACKS II — Extras → Manage imports → Adventures** tab → **Write Adventure**) checks a map's page without fetching the PDF when its picture is already made; a map that traces walls still reads the PDF. A book's saved text from before this change is read again, once, by the next GM seat to need it. When a staged book's PDF page is pointed at another file, every open seat now reads the new file and never records the old file's text as the new one's.
