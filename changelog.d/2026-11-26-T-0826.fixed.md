- **A body of an organisation roll is no longer minted as a leader where its family template's Role axis has no default.** The beastman family templates an import writes gave their Role axis the rank and file as its default only when it created the axis, so an axis without that default, and without a rank-and-file cell, rolled among every option and a body could come out a champion or a chieftain. The import now writes the rank and file as the Role default on every write, a default a Judge set on the axis stays, and a repair in place keeps it. A body takes no leader role even from a template imported earlier: where its Role axis has neither a default nor a rank-and-file option, the body takes no role. A template imported earlier gets the default written with Settings tab → Game Settings → ACKS II — Extras → Manage imports → (Re)import individual entries, with its row ticked (Repair in place).
