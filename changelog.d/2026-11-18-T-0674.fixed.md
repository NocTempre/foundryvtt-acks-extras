- **Text printed inside a picture is read on a host that serves module files from a separate file server (Settings tab → Game Settings → ACKS II — Extras → Manage imports, the steps that import the Judges Journal's scenarios):** on such a host the reader that turns a picture's text into words could not start, because a browser refuses a worker whose script sits at another address than the game's. There the reader is now started the way a browser allows. A self-hosted or desktop game starts it as it did.
