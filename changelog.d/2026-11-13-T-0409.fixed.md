- **The marching column follows the book's frontage and rank interval, not the grid.** On a square map where
  the Revised Rulebook's tables are imported, the party's column (drawn behind the party token on the map)
  stands each member in a square as wide as their frontage, sets files side by side at the sum of those
  widths and ranks one rank interval apart along the way the party walked. A combat deploy puts each member's
  token on the spot their square marks, even between grid squares, unless a wall would touch it there, in
  which case that member's token takes the grid square its spot falls in; the column's lights and the
  mapper's place read the same spots. With the tables not imported the column holds one square per member. The
  frontage rows arrive with Rules tables: run the Reimport One Shelf (GM) macro in `Compendium Packs → ACKS II —
  Extras → Macros → ACKS Extras Macros → Import from your books`, with the Revised Rulebook open, then read
  the three frontage rows under `Settings tab → Game Settings → ACKS II — Extras → Imported Rules Tables →
  Open Ruledata Browser`.
