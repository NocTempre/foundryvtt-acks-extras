- **A class whose variant table prints a heading names its path group by that heading.** After Settings tab → Game Settings → ACKS II — Extras → Manage imports → Import tab → **Import everything**, the class sheet's Paths tab labels the group with the heading the page prints over the table's first column, where it read "Variant" for every class; the group's key is the heading's too.
