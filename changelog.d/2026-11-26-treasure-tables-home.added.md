- **The treasure tables are found in one place, and the pot's rail opens it.** Open `Settings tab → Game Settings → ACKS II — Extras → Imported Rules Tables → Open Ruledata Browser`, or press the new **Treasure tables** button under Table style on a staged pot's rail (Scene controls → Token controls → New treasure pot; drawn for a seat that may modify world settings). The browser opens on the Treasure and Magic Item Tables groups, each headed by its readable name with its id beside it and a count of its overridden tables. A group lists the tables the deal reads first, and what the importer read off each page sits under a collapsed **Page reads** list with View and Export only, each row saying which table the deal reads instead; an override of one changed nothing the deal reads, so it takes none. A world with nothing imported lists the treasure tables as not supplied, and Export gives a blank page to author into. The rail's four deal choices are now one shared piece, drawn as before.
