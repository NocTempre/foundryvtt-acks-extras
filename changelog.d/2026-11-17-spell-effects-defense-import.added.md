- **Importing the Revised Rulebook and the Monstrous Manual now reads what damage against a defense needs:** resistance's fraction of damage and its save modifier arrive with the Rulebook's import (Settings tab → Game Settings → ACKS II — Extras → Manage imports) as the `defenses` rules table, and the Monstrous Manual's creatures keep their silver flaw and a susceptibility's damage multiple and save modifier, each read only where the creature's own entry prints it. A figure the books do not print stays blank. Edit the resistance figures in the Ruledata Browser (`Settings tab → Game Settings → ACKS II — Extras → Imported Rules Tables → Open Ruledata Browser`), and a creature's susceptibility figures in the monster sheet's Defenses tab, in the Susceptibilities box (Damage multiple and Save modifier); a blank one shows the creature's page reference as its tooltip.
