## 2026.11.14 — Public Beta

### Upgrading

- **Upgrading from a closed-alpha build:** this release does not read data written by earlier builds. Start in a new world, or run **Delete Everything Imported (GM)** (Compendium Packs sidebar tab → ACKS II — Extras → Macros → ACKS Extras Macros → Import from your books) and import again from your books.

### Added

### Changed

- **Classes, race item sheet:** the field for extra hit points per level past the last hit die (Items sidebar tab → a race → its sheet) and the class builder's matching hit-point rates are stored under names that no longer carry a level number. <!-- no-shot: storage names only; the field's face on the sheet is unchanged -->
- **Henchmen, formation, markets, equipment, vehicles, influence and classes text:** hints, refusals and chat lines that restated a rule from the book now say what the field, result or record does, and keep their page reference. A result hint names the result and its page; a refusal names what was compared, such as an attempt already recorded at the character's current level. The influence roll's chat card no longer adds a note about intimidation beside its result, and examples that quoted a printed figure are gone. Language strings that nothing read any more are removed. <!-- shot: henchmen-result-hint -->
- **Importer, adventure creatures:** an adventure or Lairs & Encounters creature whose stat line prints hit dice and no hit points now takes hit points from its dice on import, and a scenario creature gets one weapon for each attack routine its line prints. <!-- shot: importer-npc-routines -->

### Removed

- **The Discord bridge is not part of this release.** The Discord bot and its two settings menus, **Discord Bot** and **Discord Members** (`Settings tab → Game Settings → ACKS II — Extras → Discord Bot` and `… → Discord Members`), are gone from the module. <!-- no-shot: the surface is removed -->

### Fixed

- **A character reaches a place by its player's ownership, a pin, standing at it or a vault; a Judge named as an
  owner does not count.** Foundry names whoever creates a character or a place as its owner, so a deposit, a coin
  payment or an exchange does not count a Judge, an assistant Judge included, as an owner when it asks whether a
  character reaches a place. A Judge-made character and an unlinked place that Judge made, or a Judge-only NPC and
  any unlinked place, therefore do not reach each other by that shared owner. To put a place within reach, pin it to
  the character (drag the place from the Actors sidebar tab onto the character's sheet), give the player ownership
  of it (Actors sidebar tab → right-click the place → Ownership), or stand the character at it. Retrieving goods
  from a place stays open to the character's owner.
- **Import Everything reads the library once per step.** Core asks the server for an empty list of documents twice per compendium update, and the server answers by scanning the whole pack; that empty request is answered without the server. The skill-ladder cache reads the world's Item packs once after item changes stop for a second, ignores a character's own items, and keeps the newest read. Run it from Settings tab → Game Settings → ACKS II — Extras → Manage imports → Import Everything.
- **Import Everything reads each PDF page once per step.** The rules-tables step and the abilities update share their page reads, so each page is read once per run. Import Everything is in Settings tab → Game Settings → ACKS II — Extras → Manage imports.
- **A trap reads the party's ranks as the column stands on the map.** When the party token walks into a trap
  (a Trap Zone region or a trapped wall), the Judge-only card in the `Chat` sidebar tab takes each member's
  rank from the column drawn behind the party token: a blank square and every body of a stack take their ground,
  and a member a wall squeezes out of a rank stands a rank back, so they meet the trap later and sit farther from an
  area effect. Where the Revised Rulebook's frontage tables are imported and the map is a square grid, a rank is the
  imported rank interval deep, which sets how many ranks an area trap's radius reaches and how far a searcher's reach
  is cut by the rank they stand in; with nothing imported a rank keeps the module's standing rank depth. The frontage tables arrive
  with Rules tables (the Reimport One Shelf (GM) macro in
  `Compendium Packs → ACKS II — Extras → Macros → ACKS Extras Macros → Import from your books`).
- **The marching column follows the book's frontage and rank interval, not the grid.** On a square map where
  the Revised Rulebook's tables are imported, the party's column (drawn behind the party token on the map)
  stands each member in a square as wide as their frontage, sets files side by side at the sum of those
  widths and ranks one rank interval apart along the way the party walked. A combat deploy puts each member's
  token on the spot their square marks, even between grid squares, unless a wall would touch it there, in
  which case that member's token takes the grid square its spot falls in; the column's lights and the
  mapper's place read the same spots. With the tables not imported the column holds one square per member. The
  frontage rows arrive with Rules tables: run the Reimport One Shelf (GM) macro in `Compendium Packs → ACKS II —
  Extras → Macros → ACKS Extras Macros → Import from your books`, with the Revised Rulebook open, then read
  the three frontage rows under `Settings tab → Game Settings → ACKS II — Extras → Imported Rules Tables →
  Open Ruledata Browser`.
- **Token sizing reads the square from the monster book import.** What one battle-grid square is worth
  comes from the Monster Size table of the Monstrous Manual import (`Settings` tab → `Game Settings` →
  `ACKS II — Extras` → `Manage imports` → Rules tables), beside the frontage it multiplies, and a Judge can
  edit it in the Ruledata Browser. A token whose square or size frontage is not imported keeps the size it
  has, and the assistant's Rescale tokens notice says so. The assistant's distance chips and its unentered
  map-cell default follow the scene's own grid distance.
- Rebuild or Repair on a book writes the book's own rows as well as its shelf items (Settings tab → Game Settings → ACKS II — Extras → Manage imports → Rebuild, or Repair everything on the Import tab): the bestiary's creatures, templates and families, the rules book's vehicles and journal page, and the Judge's book's roll table are written over in place, and what the world lacks of them is imported. A beastman template comes back in the current shape under the same id, and a copy of it in the sidebar is left alone. The confirm names the book's own rows. A bestiary repair refills every creature of the book it holds, so it takes minutes.
- The trap rules read their distances and dice from the books you import. The automatic search's reach (bare and with a pole), how far a pole probes ahead of its bearer, the secret die and the band that springs a trap, how far a Trapbreaking attempt reaches, the botch band of each Trapbreaking mode, the methodical bonus and a spiked pit's dice come from the Revised Rulebook and Judges Journal when Rules tables are imported, and the pit's per-depth die is the fall table's. Edit any of them in `Settings tab → Game Settings → ACKS II — Extras → Imported Rules Tables → Open Ruledata Browser`. A rank's depth is the column's imported interval, else the scene's cell size (Scene config → Grid). A figure that is not imported is said on the card, the Trapbreaking dialog or the trap sheet: with no trigger die or band a crossing is rolled by hand, with no pole lead no pole probes, and with no fall table a pit deals no derived damage. A trap's "Springs on" field on the trap sheet is blank to read the imported band, and a number typed there wins.
