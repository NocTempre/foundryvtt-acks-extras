release its current screenshot was taken in.

stale that image is — that is the audit, visible at a glance. Link here from the
README and from release notes, never to a raw PNG path, so those links survive
the next refresh.

**Nine rows were not re-shot for 3.0.0**, against the rule that a major
re-shoots every feature area. Each needs a state a rendered document does not
reach on its own — a settings window scrolled to one control, the storage
manager mid-move, a refusal toast, a chat card behind the collapsed-sidebar
gotcha, the extended monster sheet behind the card, a lit lamp equipped, a
token on a canvas, a throw editor opened from a declaring ability, a slot
picker opened from worn gear. The 3.0.0 pass prioritized the sixteen it could
stage as disposable fixtures; the palettes in the stale nine are old, the
features themselves current.
