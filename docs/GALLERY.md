# Gallery

**Eleven plates — one per feature guide.** This is the highlight reel, not the
archive: for each feature area, the one shot that best answers "what does this
module actually do?", and nothing else.

Every other screenshot lives in the guide that explains it, beside the prose it
illustrates. That is where a shot earns its place — a reader who wants the trap
card is already reading about traps. A shot in neither this table nor a guide is
still on disk under `releases/`, the permanent record of what a release looked
like; this table is curation, not inventory.

A row pointing at an older `v<X.Y.Z>/` directory is a truthful statement of how
stale that image is — that is the audit, visible at a glance. Link here from the
README and from release notes, never to a raw PNG path, so those links survive
the next refresh.

## Adding to it

A release adds a row here only when it opens a **new feature area** — which is
rare, and is what "one per guide" means. Everything else a release shoots goes
into the guide that explains it, and stays there.

Two moves are always right: **replacing** a plate with a newer shot of the same
area, and **retiring** one whose area has a better shot in its guide. The move
that made this page a slideshow was growing it past one row per guide, so that
is the one to refuse.
