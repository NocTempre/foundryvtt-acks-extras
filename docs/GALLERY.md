# Gallery

**Twenty-four plates — one per feature area.** This is the highlight reel, not the
archive: for each feature area, the one shot that best answers "what does this
module actually do?", and nothing else.

Every other screenshot lives in the guide that explains it, beside the prose it
illustrates. That is where a shot earns its place — a reader who wants the trap
card is already reading about traps. This table is curation, not inventory.

Link here from the README and from release notes, never to a raw PNG path, so
those links survive the next refresh.

## Adding to it

A release adds a row here only when it opens a **new feature area** — which is
rare, and is what "one per guide" means. Everything else a release shoots goes
into the guide that explains it. The `releases/` folders hold a release's
shots for the guides and this table to point at; they are not a record, and a
folder is pruned once a later release's shots have replaced what it held.

Two moves are always right: **replacing** a plate with a newer shot of the same
area, and **retiring** one whose area has a better shot in its guide. The move
to refuse is growing it past one row per guide, which turns this page into a
slideshow.
