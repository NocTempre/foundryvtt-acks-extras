# Plan: repair against `acks` 14.2.0

In flight. This file is the hand-over between the sessions that work the
repair: each phase session reads it, runs its agents, appends to "Results" and
corrects the next phase's start prompt. It is deleted when the last slice has
landed and its substance has moved into the feature MODEL and DECISIONS files.

## The ruling

The owner, 2026-11-24: "Start an upgrade repair for the core system.  Anything
that now duplicates needs rolled into calling core instead of parallel code
maintenance. Use agents purposefully to plan investigate and execute." And the
same day: "I also cut corners on the last release. Those tests are overdue and
already found issues."

Where `acks` 14.2.0 does something a module surface also does, the module
deletes its version and calls core's, and keeps only what core does not cover.
Example: `scripts/equipment/effects.mjs` writes an armour-base correction
because 14.1.0's `computeAC` let a helmet replace the suit. 14.2.0 sums every
equipped armour, so the correction goes and AC is core's alone.

1. **A play stamp moves at the migration** (read from code, not observed: the

   stored `system` and each embedded item's `system`. 14.2.0's migration
   rewrites those, so a pregen imported before the upgrade reads as changed on
   a repair and `pregenDefault` offers `restore`.

   `equipment/item-sheet/snapshot.mjs` reads `quantity.max`, which the system
   dropped.

   update and re-issues it, so `await item.update({"system.equipped": true})`
   answers undefined at once and the write lands 15 to 90 ms later (measured).
   An unequip fired inside that window finds nothing to change and is lost.
   `architect` traced the module's own callers as not reading the state back.

   the first unequip after a seat loads took about 3.3 s to come back
   (measured twice; later ones 24 ms). Whether either predates this work was
   not measured.

   grip after the system's migration (S8's implementer, from source).
6. `scripts/lib/senses.mjs` suppresses the shadowy senses on `deafened`; the
   system's m6 sends a legacy `silence` to `mute`, so a migrated silence no
   longer suppresses them.
7. Stale statements that a page-side create "replaces `system` unless `items`"

   monsters and vehicles; `domains/domains.mjs` `promoteVassal` and
