## Mechanics this session learned (cloud container)

- **The checkout is shallow, and the commit tool needs full history.** Run
  `git fetch --unshallow origin` once before `acks-commit` `land`. On a shallow
  repo `git clone --shared` cannot see the private-index tree and the gate fails
  with `failed to unpack tree object`.
- Land with `--no-push`, then push the session branch yourself:
  `git push origin HEAD:ccr-167b82c5-x6l0af`. The tool's own push targets
  `main`, which waits for the owner (TOOLCHAIN §2).
- A hand `git commit` is refused here. Use the commit tool. If the edit ledger
  recorded nothing (the session started outside the repo, so the hooks never
  loaded), name the files in `change.json` (`files: {path: {whole: true}}`,
  `added: [...]`).
- No live walks are possible here. Every runtime fix lists its walk as
  "not walked" in the PR, naming the feature's `TESTING.md` recipe.
