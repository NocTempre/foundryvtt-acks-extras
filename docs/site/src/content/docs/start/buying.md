This module automates rules; it does not contain them. You need the books, and you
need Foundry VTT to run it in. Both are bought from their publishers — nothing on
this page is sold by, or earns anything for, this project.

The tabletop this module runs in. One perpetual licence, bought once; only the
Game Master needs one, and players join for free.

## The ACKS II game system for Foundry

Free, and separate from this module. It is the system that teaches Foundry what an
ACKS character is; this module extends it. Install it first.

<ul class="acks-buy">
  <li>
    <h3>ACKS II system (<code>acks</code>)</h3>
    <p>Maintained by Autarch LLC. Free and open on GitHub, and installable from Foundry's own system browser by searching for <strong>ACKS</strong>.</p>
    <p><a href="https://github.com/AutarchLLC/foundryvtt-acks-core">github.com/AutarchLLC/foundryvtt-acks-core</a></p>
  </li>
</ul>

Published by **Autarch LLC**. The module draws on the *Revised Rulebook* and the
*Judges Journal*; optional features additionally draw on the *Monstrous Manual*
(monstrous henchmen, the Full Monster Sheet), the *Treasure Tome* (ring slots,
named items) and *By This Axe* (dwarven cultures and castes).

## Getting the tables into Foundry

The module ships **no book text** — its sample tables are placeholders, and its
compendium descriptions are authored restatements with page citations.

To use the real tables, the importer built into the module reads content from
**your own PDFs** into the structures the rest of it owns — see
[Importing from your books](../../guides/importer/). Everything works before
you import; several features simply have more to work with once the tables are
in.
