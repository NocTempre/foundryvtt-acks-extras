# ACKS II — Extras

Rules automation for the ACKS II system: proficiencies and class powers,
equipment and fighting styles, exploration formations, henchmen and hirelings,
influence and reactions, locations and storage, and the full Monstrous Manual
stat block — over shared primitives and one rules-table registry.

A Foundry VTT module that extends the
[ACKS II game system](https://github.com/AutarchLLC/foundryvtt-acks-core).

## Requirements

- Foundry VTT v14+
- ACKS II system (`acks`) v14+
- [lib-wrapper](https://github.com/ruipin/fvtt-lib-wrapper) v1.12.0+
- [socketlib](https://github.com/manuelVo/foundryvtt-socketlib) v1.1.0+
