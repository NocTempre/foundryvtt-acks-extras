# lib — the shared subsystem's index

One row per file, maintained by hand: **nothing gates this table**, so a new
helper whose row was not written is invisible exactly where a reader looks for
it. **Check this table before writing any helper** — most "missing" utilities
are a row below.

Access rule: internal code imports directly from `scripts/lib/<file>.mjs`;
`globalThis.acksExtras.lib` is the EXTERNAL contract (the importer, macros,
sibling modules) — never the import path for this module's own features.

| `a11y.mjs` | `associateLabels` — every caption in EVERY rendered window (this module's, the system's, Foundry's) bound to the control it fronts, with an id seeded from that window's own root id. | `window-title.mjs` | `watchWindowTitle` — a window title its header cuts short, shown whole in Foundry's tooltip on a hover, on every ACKS surface; `clippedTitle` is the reading, taken at the hover, so a resize needs nothing. | `client-pins.mjs` | `clientPages` — every page this client draws in, the main document and each detached browser window's — and `pinLook` / `pinTheme` / `pinFontScale`, which set or release the look, theme and type-size marks on each of them. | `world-time.mjs` | The one switch deciding whether this module writes `game.time`, the one watcher for a clock that moved, and `clockReading` — the hour, and whether it is dark by the two hour settings (`darkBounds` / `isDarkAt` are the Foundry-free halves). `calendarDay` / `calendarSeason` read the day the clock stands in and the calendar's declared season (`calendarDayOf` is the pure half); null where the clock keeps no calendar or no season. `dayOfWorldTime` dates any reading, a past row's included, falling back to 86400-second days without a calendar. |
| `sheet-claim.mjs` | This module's sub-types open on this module's sheets: takes the default back from a stored `core.sheetClasses` pin (which outranks every later `makeDefault`, permanently), clears that pin once as GM, and stands a partial under the name the system's item sheet builds from a type so a foreign sheet degrades to a note instead of a thrown render. Imported LAST from `scripts/module.mjs`. |
| `sheet-rows.mjs` | How a sheet writes a list of rows without losing what it does not show: `keepUnrenderedFields`, called from `_processFormData` and from the importer's repair in place (`importer/refresh.mjs`), fills each row the form or the build sent from its stored twin (a row is cleaned whole, so a field no input renders would reset); `rowListUpdate` is the update an add or delete control writes — the OUTERMOST list its path runs through, since an update keyed through a row's index replaces that list with the one row. Foundry-free. |
| `picks.mjs` | A STAGING PICK — a control an action reads when pressed and nothing stores (`data-pick="<key>"`, no `name`): `readPicks` / `restorePicks` carry its value across a re-render from a sheet's `_preSyncPartState` / `_syncPartState` when the user changed it (`pickChanged`), so a pick rendered from the document still shows a newer stored value; `spendPicks` marks one read before an action writes it; and `isPick` is the test a submit-on-change handler returns on, since core submits on every control's change. `PicksMixin` wraps a `HandlebarsApplicationMixin` window with all three; the faction, location, group and item sheets, the demand generator and the storage manager use it, and the party sheet carries the two sync overrides inline. Foundry-free. |
| `header-band.mjs` | `moveBandIntoHeader` — a sheet's title band, rendered as a part, moved into the window header so the header stays the drag handle and the band's fields stay in the form. Called from `_onRender`. The frame and the domain sheet use it; the item and party sheets still carry copies of their own (docs/lib/ROADMAP.md). |
| `frame.mjs` | The sheet frame's Foundry half: `FRAME_CLASS`, `FRAME_TEMPLATES`, `FRAME_ACTIONS`, `FRAME_VIEW_ACTIONS`, `FRAME_WIDTHS` and `FrameMixin` — the fold, the band in the header, the view-only actions live on a read-only seat, the menu under a rail cell, the pins. Every actor sheet drawn on the frame extends it; the partials are `templates/lib/frame/`, the rules `styles/lib-frame.css` (docs/lib/MODEL.md, "The sheet frame"). |
| `frame-model.mjs` | The frame's decisions on plain data: the flags (`FOLD_FLAG`, `SHEET_FLAG`, `sheetFlag`), the save keys and glyphs, the movement modes, the AC readings, and the cells — `xpBar`, `hpCell`, `acCell`, `moveCell`, `saveCells`, `partyCell` — with `resolveTab`, the pins and `loadBar`. Foundry-free; the character sheet's view-model and constants re-export it. |
| `ui-preset-logic.mjs` | The default-sheet ladder a world's UI preset resolves (extras, then the system, then Foundry). Foundry-free. |
| `ui-preset.mjs` | The UI preset: whose defaults a world opens on, its look and its default sheet per type, chosen once by the Judge for every seat. |
| `module.mjs` | The barrel + patch layer: builds `acksExtras.lib`, registers settings, sub-types and patches. Import FROM the individual files, not from here. |
