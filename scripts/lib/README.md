# lib — the shared subsystem's index

One row per file, maintained by hand: **nothing gates this table**, so a new
helper whose row was not written is invisible exactly where a reader looks for
it. **Check this table before writing any helper** — most "missing" utilities
are a row below.

Access rule: internal code imports directly from `scripts/lib/<file>.mjs`;
`globalThis.acksExtras.lib` is the EXTERNAL contract (the importer, macros,
sibling modules) — never the import path for this module's own features.

| `weapons.mjs` | Which kind of weapon a grid row is: `resolveRows(grid, lists)` places each row of the weapons grid (`equipment/weapon-rows.mjs`) on a proficiency category, a Weapon Focus, a damage type and the two-hands list by matching the NOUN LISTS the importer read (`weaponLists()`, the `weaponLists` document) against the row's name, then its grid sub-header, then the kind the other rows under that sub-header were placed into when they agree on one; an ambiguous or unmatched row stays unplaced, `placedBy` says whether the name, the block or the sub-header's mates placed it, and a missing list places nothing. Foundry-free; not on the lib api yet. |

Foundry-free. |

| `core-windows.mjs` | `openCoreWindow` — the ONE way this module opens one of the system's own character windows (Tweaks, Mortal Wounds, Tampering with Mortality, the Modifiers summary, the Scores Generator) from a window that is not the system's sheet, with a warning when the system no longer has it. |
| `services.mjs` | Named-contract service registry — providers register at `init`, consumers look up by contract name (contracts: `docs/lib/API.md`). |
| `turn-activities.mjs` | The turn plan's registry and its pure helpers: `registerTurnActivity` (what a party member can spend a stationary turn on; returns its unregister), `offeredActivities`, `lockActivity` / `unlockActivity`, `advanceTurn` (counts the plan down and stamps due entries before anything resolves), `resolveDue`, `cancelForCombat`, and `partyRest` (every member who owes rest chose Rest). Foundry-free; not on the lib api yet (docs/lib/MODEL.md, "The turn-activity registry"). |
| `automation-client-logic.mjs` | `createSeatElection` — which window of a seat leads it: the last claim the server relayed, applied by every window in the order it reads it. Foundry-free. |
| `automation-client.mjs` | The election's window half, joined at `ready` over the `sockets.mjs` channel: `isLeadClient`, `automationSettled`, `automationCensus` (docs/lib/MODEL.md, "Which window automates"). | `sockets.mjs` | The module's ONE cross-client transport (socketlib + handler registry + native fallback). |

| `a11y.mjs` | `associateLabels` — every caption in EVERY rendered window (this module's, the system's, Foundry's) bound to the control it fronts, with an id seeded from that window's own root id. The ONE answer to "a `<label>` that names nothing"; never write a literal `id=` in a `.hbs` instead, two copies of one sheet collide. |
| `window-title.mjs` | `watchWindowTitle` — a window title its header cuts short, shown whole in Foundry's tooltip on a hover, on every ACKS surface; `clippedTitle` is the reading, taken at the hover, so a resize needs nothing. | `window-resize.mjs` | `installWindowResize` — the ONE hook that gives every window naming a class of this module its drag corner; `isModuleWindow` is the reading. | `client-pins.mjs` | `clientPages` — every page this client draws in, the main document and each detached browser window's — and `pinLook` / `pinTheme` / `pinFontScale`, which set or release the look, theme and type-size marks on each of them. The ONE way a client-wide attribute, class or custom property is written; never write one to `document.documentElement` or `document.body` alone, which leaves a detached window as it was. `keepDetachedMarks` keeps core's own `detached` class on each detached `<body>`, which core's interface pass writes over. |
| `world-time.mjs` | The one switch deciding whether this module writes `game.time`, the one watcher for a clock that moved, and `clockReading` — the hour, and whether it is dark by the two hour settings (`darkBounds` / `isDarkAt` are the Foundry-free halves). `calendarDay` / `calendarSeason` read the day the clock stands in and the calendar's declared season (`calendarDayOf` is the pure half); null where the clock keeps no calendar or no season. `dayOfWorldTime` dates any reading, a past row's included, falling back to 86400-second days without a calendar. |

Foundry-free. |
| `header-band.mjs` | `moveBandIntoHeader` — a sheet's title band, rendered as a part, moved into the window header so the header stays the drag handle and the band's fields stay in the form. | `frame.mjs` | The sheet frame's Foundry half: `FRAME_CLASS`, `FRAME_TEMPLATES`, `FRAME_ACTIONS`, `FRAME_VIEW_ACTIONS`, `FRAME_WIDTHS` and `FrameMixin` — the fold, the band in the header, the view-only actions live on a read-only seat, the menu under a rail cell, the pins. | `press-focus.mjs` | `PressFocus` — keyboard focus across a press that re-renders its window: remembers the pressed `[data-action]` control by its `data-*` identity and focuses its successor after the render, only where focus was lost to it. `FrameMixin` owns one per sheet, so every frame sheet has it; wire it by hand only on a window outside the frame. |
| `frame-model.mjs` | The frame's decisions on plain data: the flags (`FOLD_FLAG`, `SHEET_FLAG`, `sheetFlag`), the save keys and glyphs, the movement modes, the AC readings, and the cells — `xpBar`, `hpCell`, `acCell`, `moveCell`, `saveCells`, `partyCell` — with `resolveTab`, the pins and `loadBar`. | `ui-preset-logic.mjs` | The default-sheet ladder a world's UI preset resolves (extras, then the system, then Foundry). Foundry-free. |
| `ui-preset.mjs` | The UI preset: whose defaults a world opens on, its look and its default sheet per type, chosen once by the Judge for every seat. |
| `module.mjs` | The barrel + patch layer: builds `acksExtras.lib`, registers settings, sub-types and patches. Import FROM the individual files, not from here. |
